# Piada Ruby on Rails Sample Project

## Getting Started / Running the Project

> Rails Version `8.1.3`
> Ruby Version  `3.4.9`


* Database creation
`rails db:create`
`rails db:migrate`


> Running the project
> procfile.dev
`bin/dev` on Unix
> web: bin/rails server -p 3000
> css: bin/rails dartsass:watch

Old Procfile.dev, now using bundle for Windows, and git bash

css: bin/rails dartsass:watch
